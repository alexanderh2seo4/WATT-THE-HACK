# Bundesnetzagentur electricity interruption data

Downloaded on 2026-10-24 from the [Bundesnetzagentur electricity indicators page](https://www.bundesnetzagentur.de/DE/Fachthemen/ElektrizitaetundGas/Versorgungssicherheit/Versorgungsunterbrechungen/Auswertung_Strom/artikel.html?gtp=861764_list%253D2).

## Files

- `national_indicators_2006-2024.pdf` — nationwide electricity reliability indicators, 2006–2024; current file linked by the agency.
- `state_level_saidi_since_2008.xlsx` — Bundesländer SAIDI values since 2008; current file linked by the agency.
- `national_indicators_2006-2022_archived.xlsx` — older, machine-readable indicator workbook recovered from the agency's archived page (covers 2006–2022).
- `incident_records_2012.xlsx` — historical incident workbook recovered from an archived copy of the agency's download.
- `incident_records_2013.xlsx` through `incident_records_2024.xlsx` — annual incident workbooks currently linked by the agency.

## Coverage note

The agency's current page lists individual incident workbooks for 2013–2024. An archived version of its earlier page listed 2008–2016, but the live download archive no longer serves the 2008–2011 files; the archived 2011 copy was incomplete and is not included. The earlier page did not list individual incident records for 2006–2007. The summary indicators do cover those years. Treat unavailable incident years as missing data, not as zero incidents.
